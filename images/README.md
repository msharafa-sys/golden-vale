# صور الملف التعريفي
المصدر: 5 صور أرسلها المؤسس (مصدرها الأصلي غير موثّق). تُعالَج بـ `process_photos.py` (قصّ ونسبة وتحسين خفيف).
كل صورة تحمل في الملف وسم «صورة توضيحية»؛ ليست من أعمال Golden Vale.

| الناتج | المصدر | المكان |
|---|---|---|
| svc-ads | 5.jpg (واجهة محل) | الدعاية والإعلان |
| svc-events, overview | 4.jpg (مسرح وإضاءة) | تنظيم الفعاليات + النظرة العامة |
| svc-brand | 8.jpg (صالة استقبال) | إدارة الهوية البصرية |
| svc-exp | 6.jpg (منصة عرض) | التجارب الإبداعية (دقة منخفضة، 740px) |
| method | 7.jpg (قاعة مؤتمر) | آلية العمل — قصّ على المقاعد دون الشاشة |

**قبل التوزيع:** تأكد من حقوق استخدام الصور (4 و5 و6 تبدو مولّدة بالذكاء الاصطناعي، و7 تبدو صورة فعلية لفعالية جهة أخرى بأشخاص ونص برتغالي)، واستبدلها بصور مرخّصة أو من أعمالكم.
